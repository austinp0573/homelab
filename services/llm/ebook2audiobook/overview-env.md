# ebook2audiobook env

manual GPU TTS workload. exclusive vs llama / Whisper / ComfyUI.

| name (key) | default value | purpose + notes |
| --- | --- | --- |
| `COMPOSE_PROJECT_NAME` | `llm-ebook2audiobook` | Compose project for the Gradio ebook→audio stack. Keep it separate from llama/speech so `down` only kills this GPU hog. Because restart is `no`, the project mainly exists for naming consistency and volume binds. I bring this up only when converting, then tear it down before starting llama again. |
| `CONTAINER_NAME` | `ebook2audiobook` | Stable container name for logs and GPU debugging. Not shared-DNS critical like llama-cpp, but scripts and muscle memory use this string. A second copy with a different name will still try to grab the same AMD device — exclusivity is GPU-level, not name-level. Stop the named container before bringing llama back or you will still be sharing one AMD GPU. |
| `RESTART_POLICY` | `no` | Intentional: this is a manual batch/UI workload, not a daemon. After reboot it stays down so it cannot steal the GPU from llama on boot. If you set `unless-stopped` you will fight exclusivity every reboot. Start with `up`, convert, then `down`. |
| `EBOOK_IMAGE` | `athomasson2/ebook2audiobook:rocm` | ROCm-enabled ebook2audiobook image. CPU tags will appear to run and then take forever on long books. Image pulls are large; pin or record what worked with your gfx. Do not run alongside other ROCm containers on the same GPU. |
| `EBOOK_BIND` | `127.0.0.1` | Gradio UI bind on the host. Loopback + SSH tunnel is the default trust model. Publishing to LAN exposes a heavy GPU app with whatever auth Gradio does or does not have. Keep it local unless you put a real gate in front. |
| `EBOOK_PORT` | `7860` | Host port for the Gradio UI (classic Gradio default). Collides with other Gradio apps (Comfy sometimes nearby in spirit). Only matters while the container is up given `restart: no`. Browser hits `HOST:7860`, not the llama ports. |
| `EBOOKS_DIR` | `/opt/llm/ebooks` | Host input directory for source ebooks. Mount persistence outside the git tree. Drop files here before convert; empty dir means empty UI library. Do not reuse the audiobook output path or you will overwrite inputs with outputs. |
| `AUDIOBOOKS_DIR` | `/opt/llm/audiobooks` | Host output directory for finished audio. Can grow huge — plan disk. Separate from `EBOOKS_DIR` on purpose. Back up what you care about; tmp and models dirs are not substitutes for this. |
| `MODELS_DIR` | `/opt/llm/ebook-models` | TTS model cache/weights for this app — not the llama GGUF directory. Mixing GGUF chat models here does nothing useful and confuses disk accounting. Pre-pull/populate so the UI does not redownload into a tiny root fs. Keep it on fast local disk if you can. |
| `VOICES_DIR` | `/opt/llm/ebook-voices` | Voice packs / speaker assets the converter references. Persist so you do not re-fetch voices every run. Wrong permissions show up as missing voice errors mid-job. Keep distinct from Piper's `TTS_DIR` under speech — different stacks, different layouts. |
| `TMP_DIR` | `/opt/llm/ebook-tmp` | Scratch space for intermediate audio/chunks. Needs room during long books; filling the disk mid-convert corrupts outputs. Safe to wipe when the container is stopped. Do not point this at a network mount that cannot handle small-file churn. |
| `EBOOK_LANGUAGE` | `eng` | Default language passed through `convert.sh --language` and related helpers. Wrong language wrecks pronunciation and model selection. Override per book when needed rather than changing the default for one-offs. Keep consistent with the voice packs you actually installed. |
| `HIP_VISIBLE_DEVICES` | `0` | AMD GPU index visible to the ROCm TTS process. Same exclusivity rules as llama and Whisper — one heavy consumer. Wrong index looks like CPU fallback or init failure. Coordinate stops: llama down, Whisper down, Comfy down, then start this. |
| `HSA_OVERRIDE_GFX_VERSION` | *(empty)* | Leave unset unless ROCm demands an override for your card. Copied-wrong values break kernels harder than an empty setting. Only set after `rocminfo` + a failed start prove you need it. Same caution as the llama-cpp stack. |
