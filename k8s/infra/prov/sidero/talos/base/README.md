# minimal talos bootstrap patches

strategic-merge patches over Omni-generated Talos configuration, not
standalone machine configurations

- `common.patch.yaml` DNS for static nodes, pins KubePrism to port
  `7445`, the local Kubernetes API endpoint used by Cilium.
- `controlplane.patch.yaml` removes only the control-plane scheduling taint and
  external-load-balancer exclusion label.
- `worker.patch.yaml` is available for worker registration.

Cilium's complete feature configuration and Longhorn's values remain under
`infra/net/cilium/` and `infra/stor/longhorn/`. This simplification does not alter
those values, extension selections, or existing disk provisioning.

Render the Omni template offline with `omnictl cluster template render`, then
check patches over a temporary config generated by the matching `talosctl`
version. Use `talosctl validate --mode metal --strict` on the merged config.
Generated standalone configs contain private credentials: keep them temporary
and never apply them to Omni-managed nodes.

Talos validation does not validate embedded Kubernetes admission schemas. The
patches intentionally leave admission configuration entirely to Omni/Talos.
